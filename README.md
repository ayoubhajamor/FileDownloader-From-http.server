# FileDownloader-From-http.server
## Installation
```bash
git clone git@github.com:ayoubhajamor/FileDownloader-From-http.server.git
cd FileDownloader-From-http.server
mkdir .venv
python3 -m venv .venv/
source .venv/bin/activate
pip install -r requirements.txt
```
## Usage
```bash
python3 downloader.py <host> <port>
```
